🚀 COMECE EM 3 PASSOS

   PASSO 1: Backend
   ────────────────
   $ cd backend
   $ npm install
   $ npm start
   
   ✅ Server rodando em http://localhost:3000

   PASSO 2: Frontend (outro terminal)
   ─────────────────────────────────
   $ cd frontend
   $ python -m http.server 8000
   
   ✅ Server rodando em http://localhost:8000

   PASSO 3: Abra no navegador
   ──────────────────────────
   http://localhost:8000/frontend/index.html
   
   ✅ Pronto! Teste signup → login → barbearias → agendamento
