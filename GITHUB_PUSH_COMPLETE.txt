🚀 COMO CLONAR E USAR

OPÇÃO 1: Clone Fresh
────────────────────

$ cd JUMP

OPÇÃO 2: Seu Local Já Tem Git
──────────────────────────────

INICIAR A APLICAÇÃO
────────────────────
Terminal 1 (Backend):
$ cd backend
$ npm install
$ npm start

Terminal 2 (Frontend):
$ cd frontend
$ python -m http.server 8000

Browser:
$ http://localhost:8000/frontend/index.html
