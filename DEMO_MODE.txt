🛠️ PARA USAR O BACKEND REAL:

1. Abra outro terminal
2. Vá para a pasta backend:
   cd backend
   
3. Instale dependências:
   npm install
   
4. Configure o arquivo .env com suas credenciais Firebase/Twilio
   
5. Inicie o servidor:
   npm start

Depois o frontend automaticamente se conectará ao backend real.

  localStorage.clear() no console

❌ PROBLEMA? TENTE ISSO:

1. Limpe o cache do navegador (Ctrl+Shift+Del)
2. Recarregue a página (F5 ou Ctrl+R)
3. Abra o console (F12) e veja os erros
4. Se receber erro de CORS, certifique-se que o backend está na porta 3000
