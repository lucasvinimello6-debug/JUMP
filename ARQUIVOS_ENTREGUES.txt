## 🚀 COMO COMEÇAR

### 1. Instale e inicie o Backend
cd backend
npm install
npm start

### 2. Inicie o Frontend (outro terminal)
cd frontend
python -m http.server 8000

### 3. Abra no navegador
http://localhost:8000/frontend/index.html

### 4. Teste o fluxo
- Clique em "Começar"
- Cadastre-se (signup)
- Faça login
- Explore dashboard
- Visite barbearias
- Teste agendamento

## 🆘 TROUBLESHOOTING RÁPIDO

Erro: "Failed to fetch"
→ Verifique se Backend está rodando em :3000

Erro: "Unauthorized"
→ Faça login novamente, session expirou

Erro: "Email já existe"
→ Use outro email para testar

Erro no Console:
→ Consulte SETUP.md → Troubleshooting

Mais ajuda:
→ Leia SETUP.md ou INTEGRATION.md
